ROUTE LOGIC

为什么这样走

路线不是把景点简单串起来，而是围绕季节、航班和山区风险倒推：先抢秋色、再走雅丹，最后用高速完成赛里木湖往返。

1

秋色优先

禾木、喀纳斯集中在9月27—29日，赶在10月1日国庆高峰前。禾木白天游，贾登峪住1晚、喀纳斯住1晚，9/29拍神仙湾晨雾后出山。

2

闭环少回头

乌鲁木齐向北走S21，经阿禾公路进入山区；从布尔津沿G3014南下克拉玛依，再接G30向西去赛里木湖，主线方向连续。

3

航班倒推

9月25日落地后在一嗨机场店取深蓝G318；10月4日15:00起飞，因此10月3日07:00离开赛里木湖返乌。四人先到酒店卸行李，再由一名司机去新疆昆仑宾馆停车场还车。

每天怎么走

“纯驾驶”不含吃饭、拍照、排队、安检和景区换乘；长途日已为两名司机安排约2小时一次的轮换节点。

紧急情况处理手册

北疆长途最重要的原则：先保护人员、再标明位置、最后处理车辆或行程。四个人不要分头行动。

高速故障或事故

  1. 开启双闪，能移动就停入应急车道或安全区，熄火拉手刹。
  2. 所有人从右侧下车，立即撤到护栏外；不要在车边拍照或争论责任。
  3. 在确保自身安全的前提下，于车后方足够距离放三角牌；高速通常至少150米，雨雪雾继续加大距离。
  4. 有人受伤先打120/122；车辆故障打12122、租车公司和保险救援。

风雪、结冰或封路

  1. 不绕过封路卡点，不跟导航钻小路；就近进入服务区、县城或有人值守的驿站。
  2. 冰雪路面降低车速、加大车距，避免急刹、急打方向和急加速。
  3. 优先删景点：五彩滩、神仙湾晨雾、观鱼台依次放弃；10/3返乌底线不变。
  4. 油量低于半箱就补，手机和充电宝保持70%以上。

无信号或山区被困

  1. 留在车辆和主路附近，不让两组情侣分开找路；夜间更不要徒步下山。
  2. 打开离线地图查看最后位置、道路方向和公里桩，保存电量并间歇尝试110/12122。
  3. 用双闪、反光背心和手电提示过往车辆；保持通风，禁止在密闭车内长时间怠速取暖。
  4. 出发前把每日路线、酒店和车牌发给家人，约定晚间报平安时间。

失温、受伤或高反不适

  1. 立即离开风雨，换掉湿衣，重点包裹躯干、颈部和头部，垫离冰冷地面。
  2. 意识清醒时小口喝温热含糖饮料，缓慢复温；不要饮酒、不要用很烫的水猛烫四肢。
  3. 持续发抖、步态不稳、意识模糊、胸痛或呼吸困难，立即打120/110。
  4. 意识不清者不要喂食饮水；根据120指导进行急救并等待救援。
打电话时一次讲清：“4人同行，伤员人数与意识状态；所在公路/景区、行驶方向、最近出口或公里桩；车牌与车型；剩余油量；天气和手机电量；回拨号码。” 出发前把租车公司、车辆保险、各晚酒店和景区电话截图离线，并在车内放一张纸质备份。
